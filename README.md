# 🖥️ Monitor de Rede

Projeto em **Python** para monitoramento de rede, com notificações e logs estruturados.  
Este projeto faz parte do meu portfólio e demonstra boas práticas de **engenharia de software** e **engenharia de dados**.

---

## 🚀 Funcionalidades (versão inicial)
- Monitoramento de conectividade (ping/requests).
- Logs estruturados com `rich`.
- Configuração via `.env`.
